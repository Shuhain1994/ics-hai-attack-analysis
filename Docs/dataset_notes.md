# Dataset Notes – HAI Industrial Control System Dataset

This document summarizes how the HAI ICS dataset is understood, scoped, and used within this project.  
It reflects an **analysis-oriented perspective**, rather than a full reproduction of the official dataset documentation.

---

## 1. Dataset Overview

The HAI Industrial Control System (ICS) dataset represents a simulated industrial environment composed of multiple interconnected process control loops, including level, pressure, flow, and temperature control.

The dataset provides:
- Time-series process data for normal operation
- Multiple labeled attack scenarios affecting different subsystems

Each attack scenario is described at a high level, without exposing internal controller logic or detailed attacker implementation.

---

## 2. Subsystems and Variables Used in This Project

This project focuses exclusively on the **P1-LC (Level Control)** subsystem.

The following variable categories are analyzed:

- **Setpoint (SP)**  
  Operator-defined or attacker-manipulated target values (e.g., `P1.B3004`)
- **Process Variable (PV)**  
  Sensor-measured physical process state (e.g., `P1.LIT01`)
- **Control Variable (CV)**  
  Actuator output commands generated by the controller (e.g., `P1.LCV01D`)

Only a minimal set of variables was selected to preserve interpretability and reduce noise during analysis.

---

## 3. Time Index and Time Zone Handling

All timestamps in the dataset include an explicit time zone offset (`+09:00`).  
Time windows were selected using absolute timestamps to avoid ambiguity and ensure reproducibility.

The analysis does not rely on relative indexing or implicit sampling assumptions.  
All comparisons between normal and attack data are performed using consistent time ranges and visualization scales.

---

## 4. Attack Scenario Structure

### 4.1 SA08

SA08 represents a setpoint manipulation attack targeting the P1-LC control loop.  
According to the scenario description, the attacker increases the setpoint and subsequently restores it using a trapezoidal profile, potentially combined with sensor value replay to mask the manipulation.

In this project, SA08 is analyzed using separate time windows for:
- Normal operation
- Attack execution

---

### 4.2 MA06 – Composed Attack Scenario

MA06 is a **composed attack scenario**, consisting of two individual attack patterns:

- **SA08**
- **SA14**

As a result, MA06 analysis inherently involves four datasets:
- SA08 – normal
- SA08 – attack
- SA14 – normal
- SA14 – attack

This structure reflects the design of the dataset rather than instability or redundancy in the analysis.

---

## 5. Scope and Intentional Exclusions

The following elements are intentionally **out of scope** for this project:

- Network traffic (e.g., Modbus, TCP/IP)
- PLC logic or controller parameter values
- Ground-truth attack success criteria
- Machine learning or automated anomaly detection

These exclusions are deliberate and aligned with the project goal of evaluating **what can and cannot be inferred from process-level data alone**.

---

## 6. Interpretation Caveats

Attack labels in the dataset indicate **intent**, not guaranteed observable impact.  
The presence of an attack label does not imply that process-level anomalies must be visible within the selected time window.

This project therefore avoids equating labeled attacks with confirmed detection outcomes.

---

## 7. Reproducibility Notes

All time windows used for analysis are explicitly documented in the main report and README.  
The analysis scripts are deterministic and rely solely on the selected CSV files and timestamp ranges.

Additional figures not included in the report are retained in the project repository for transparency.

---

## 8. Summary

These notes document how the HAI ICS dataset is interpreted and constrained within this project.  
They serve to clarify analytical choices, limitations, and assumptions, enabling informed review and reproduction of the results.
